# Etch-a-Sketch 🎨

A digital Etch-a-Sketch built with **JavaScript**, **HTML**, and **CSS**. Move your mouse over the grid to draw — just like the classic toy!

## Features
- Interactive drawing grid
- Hover to draw (black squares)
- Dynamic resizing: Choose a new grid size (1–256) at any time
- Clean, responsive design with CSS Grid

## How to Use
1. Open the project in your browser.
2. Hover over the grid to draw.
3. Click the **Reset** button to start over with a new grid size.
